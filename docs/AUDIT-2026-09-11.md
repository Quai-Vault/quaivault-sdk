# SDK audit — 2026-09-11

Release: `@quaivault/sdk@0.6.1`.

## Scope and capability review

Reviewed the SDK's public client, vault, factory, recovery, encoding/decoding,
indexer, balance, retry, polling, signer, and receipt paths against the checked-in
contract ABIs and the CLI capability contract. The ABI drift check passes against
contracts revision `48f9ef2ccc7a24243df66ac02cb9249672abf751`.

| Workflow | Coverage |
| --- | --- |
| Vault discovery, creation, prediction, registration, configuration | Public SDK methods; deployment salt validation added |
| Native/ERC20/ERC721/ERC1155 transfers and atomic batches | Proposal builders and ABI encoding/decoding |
| Owner, threshold, delay, module, delegatecall, signed-message administration | Multisig proposal builders |
| Approve, revoke, execute, cancel, expire | Lifecycle methods and outcome classification |
| Recovery configuration and full guardian lifecycle | Recovery methods, snapshots, affordances |
| Balances, history, deposits, signed messages, realtime | Indexer-backed discovery with chain verification where available |
| Raw module integration | Exported contract ABIs; module-originated execution is not an owner CLI workflow |

No missing material workflow was found in that scope. Indexer-only discovery and
history remain explicitly indexer-dependent; low-level contract getters need not
have individual CLI commands.

## Material findings fixed

- High: selected network was not checked against read/signing RPCs before signing.
  Every high-level broadcast now checks both providers and the external signer's
  Quai address. The check does not retry the transaction submission.
- High: a supplied salt could bypass the miner's address/shard checks and deploy an
  unusable vault. Validate the predicted address and deployer's zone before sending.
- High: receipt failures discarded the submitted hash and implied an ordinary failure.
  `BroadcastError` preserves it and explicitly reports an unknown outcome.
- Medium: invalid private scalars could be echoed by underlying cryptographic errors.
  Public configuration errors now omit those details.
- Medium: invalid retry/poll settings and cyclic error causes could cause unbounded or
  misleading behavior. Validate settings, bound cause traversal, interrupt poll sleeps,
  and stop waiting for a timelock that requires an explicit execute call to start.
- Dependency maintenance: upgrade Vitest to 4.1.11 and compatible transitive fixes.
  The release workflow pins actions, npm, and the audited contracts revision.

## Verification

- 251 tests pass on Node 22.23.2; typecheck, lint, build, and ABI drift checks pass.
- Both supported peers, quais alpha.55 and alpha.56, pass the SDK test/build/type gates
  (alpha.55 ran the 250-test suite before the additional timelock regression was added).
- npm audit reports zero known vulnerabilities in the resolved dependency tree.
- SDK tarball inspected; CLI integration tests pass against the packed candidate.
- Read-only mainnet smoke: chain ID 9, factory verification passed, and a live vault
  returned its three owners and threshold of three.

This is an application audit, not a formal proof or a new smart-contract audit.
No funded chain write was performed. Write failure modes are covered with controlled
providers and receipts; production RPCs and indexer availability remain external inputs.
